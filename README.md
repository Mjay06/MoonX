# Lunar Landing Site Navigator

The project foundation is set up with Next.js App Router, React, TypeScript, Tailwind CSS, and ESLint. The application route is intentionally blank; no user interface or project features have been implemented.

## Requirements

- Node.js 20.9 or later
- npm

## Commands

```bash
npm run dev
npm run lint
npm run typecheck
npm run check
npm run build
npm start
```

The development server runs at `http://localhost:3000`. Add application pages and functionality only after the architecture has been reviewed.
